# DOMEX Group — Italian Premium Website

A responsive multi-page static website using HTML, CSS (Tailwind-compatible styling) and vanilla JavaScript.

## Root files
- `index.html` — Home
- `immobili.html` — Properties
- `servizi.html` — Services
- `chi-siamo.html` — About
- `contatti.html` — Contact
- `tailwind.css` — Styling and responsive design
- `vanilla.js` — Navigation, multilingual UI and interactions
- `domex-logo.png` — Supplied DOMEX logo
- `domex-italian-villa.jpg` — Premium Italian villa visual
- `domex-hero-italian.jpg` — Refined hero photograph extracted from the new DOMEX campaign artwork
- `domex-hero-banner-reference.png` — Full campaign artwork reference
- Reference image assets retained at root

## Run
Open `index.html` in a browser or serve the folder using a static web server.

## GitHub Pages
Extract the ZIP and upload all files directly into the repository root. No nested asset folders are required.

## Important
The site is a static front-end. The contact form is a visual demo until connected to an email/CRM endpoint. Google Fonts and the Tailwind CDN need internet access; the main local imagery is bundled.


## Responsive support
The layout includes responsive breakpoints for large desktop monitors, standard laptops, tablets, mobile phones, narrow phones and short landscape screens. Navigation becomes an accessible collapsible menu on tablet/mobile widths. Images, forms, cards, galleries and footer layouts adapt to available screen width.
